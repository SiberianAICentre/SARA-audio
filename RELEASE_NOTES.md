## 0.1.0, 2026-09-15

### Обработка аудио

- Выбор второго канала оператора с управляемым fallback для mono.
- Нормализация в mono PCM 16 кГц и формирование speech-only WAV.
- Энергетический VAD, паузы, длительности и скорости речи.
- ASR через faster-whisper с временными метками слов.
- Акустические признаки openSMILE ComParE 2016.
- MIC, ASR, 92 лингвистических признака и 1024 RoSBERTa embeddings.

### Прогноз MIC

- JSON-модель фильтра записей.
- Реконструкция восьми признаков экспертной разметки.
- Группировка принятых записей по оператору и году.
- Групповой прогноз пола и выгорания.
- Компактная таблица прогноза, полная таблица для интерпретации и отдельный
  аудит фильтрации.

### Интерфейсы и доставка

- CLI для файла, каталога, диагностики ASR, smoke-test и упаковки результатов.
- Web-интерфейс Gradio с batch upload, preview и скачиванием ZIP.
- Изолированный worker process и поэтапный `processing.log` для Windows native.
- CSV, JSON, Parquet, XLSX, manifests и SHA-256 delivery package.
- Windows native CUDA 12 installer и отдельные Docker-профили CUDA 11.8/12.

### Проверенный профиль

Основной серверный профиль: Windows x64, Python 3.11, RTX 4090, ASR на CUDA 12,
CPU-only PyTorch для RoSBERTa и `config/rtx4090_cuda12.yaml`.

### Известные ограничения

- JSON моделей не содержат scaler, поэтому стандартизация признаков не выполняется.
- Интерпретация результата должна подключаться отдельным блоком после pipeline.
- Встроенный Gradio не предоставляет TLS и аутентификацию.
- Offline wheelhouse должен отдельно пройти smoke-test на целевой машине.
- Публичная лицензия пока не выбрана.
